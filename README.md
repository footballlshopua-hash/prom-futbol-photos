# prom-futbol-photos

Публічні фото товарів магазину для Prom.ua (лише оброблені фото 1200×1200).

Фото публікуються через GitHub Pages:
`https://footballlshopua-hash.github.io/prom-futbol-photos/images/<назва>.jpg`

Файли генеруються автоматично в основному (приватному) репозиторії скриптами
`scripts/process_images.py` → `scripts/publish_photos.py`. Вручну тут нічого не редагуйте.
